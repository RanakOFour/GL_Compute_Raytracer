\doxysubsubsection{Detailed Description}
Handles the interaction between pointers and vector, matrix types. 

This extension defines an overloaded function, \doxylink{group__gtc__type__ptr_gaa6abca1c01d37b11c0d524bdf74b2094}{glm\+::value\+\_\+ptr}, which takes any of the \doxylink{group__core__template}{core template types}. It returns a pointer to the memory layout of the object. Matrix types store their values in column-\/major order.

This is useful for uploading data to matrices or copying data to buffer objects.
