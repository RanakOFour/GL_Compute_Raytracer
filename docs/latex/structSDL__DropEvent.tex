\doxysubsection{Detailed Description}
An event used to request a file open by the system (event.\+drop.\texorpdfstring{$\ast$}{*})

This event is enabled by default, you can disable it with SDL\+\_\+\+Event\+State().

If this event is enabled, you must free the filename in the event.
