\doxysubsection{Detailed Description}
A structure that contains pixel format information.

Everything in the pixel format structure is read-\/only.

A pixel format has either a palette or masks. If a palette is used {\ttfamily Rmask}, {\ttfamily Gmask}, {\ttfamily Bmask}, and {\ttfamily Amask} will be 0.

An \doxylink{structSDL__PixelFormat}{SDL\+\_\+\+Pixel\+Format} describes the format of the pixel data stored at the {\ttfamily pixels} field of an \doxylink{structSDL__Surface}{SDL\+\_\+\+Surface}. Every surface stores an \doxylink{structSDL__PixelFormat}{SDL\+\_\+\+Pixel\+Format} in the {\ttfamily format} field.

If you wish to do pixel level modifications on a surface, then understanding how SDL stores its color information is essential.

For information on modern pixel color spaces, see the following Wikipedia article\+: \href{http://en.wikipedia.org/wiki/RGBA_color_space}{\texttt{http\+://en.\+wikipedia.\+org/wiki/\+RGBA\+\_\+color\+\_\+space}}
