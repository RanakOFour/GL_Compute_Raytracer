\doxysubsection{Detailed Description}
Controller device event structure (event.\+cdevice.\texorpdfstring{$\ast$}{*})

Joysticks that are supported game controllers receive both an \doxylink{structSDL__JoyDeviceEvent}{SDL\+\_\+\+Joy\+Device\+Event} and an \doxylink{structSDL__ControllerDeviceEvent}{SDL\+\_\+\+Controller\+Device\+Event}.

SDL will send CONTROLLERDEVICEADDED events for joysticks that are already plugged in during \doxylink{SDL_8h_a8fc8d35348d7c74bad8392d776c937b8}{SDL\+\_\+\+Init()} and are recognized as game controllers.
