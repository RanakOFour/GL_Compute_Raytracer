\doxysubsection{Detailed Description}
A collection of pixels used in software blitting.

This structure should be treated as read-\/only, except for {\ttfamily \doxylink{structSDL__Surface_abd9597e0e084b8ef33fe0397bc26d911}{pixels}}, which, if not NULL, contains the raw pixel data for the surface.
